# Vanish interface observations — 2026-10-01

Observed in the installed Mac app while selecting one point location. The map fills the window. A rounded smoky-glass panel floats over the left edge, with a subtle bright border and soft shadow. The map remains pale and legible; cyan is reserved for the primary action and selected position. Route controls appear in the same panel rather than opening a separate workspace. Status and secondary actions are small floating capsules or circles, leaving the map as the focus.

For ALoco, the useful pattern is the hierarchy: place search first, one obvious action, device/status information at the bottom, and route progress near the map. The user specifically liked the liquid-glass appearance. ALoco's Mac preview now uses a translucent floating panel and compact progress card, with ALoco's own logo and labels.

The selected north-end Starbucks resolved to 7620 SE 27th St, Mercer Island (47.587090, -122.236938). Vanish reported "Spoofing..." on the connected iPhone 16 Pro after Teleport. During this session that state later stopped unexpectedly after roughly 20 seconds; a second Teleport returned to "Spoofing...". The cause was not established from the UI, so this should not be treated as a reliable persistence test.

ALoco's point-teleport animation is intentionally visual. The iPhone's simulated GPS is set to the destination in one operation; the marker and line in ALoco show the transition without sending intermediate locations. Route playback remains the feature that actually moves simulated GPS along roads.
